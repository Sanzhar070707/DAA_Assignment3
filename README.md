# DAA Assignment 3: Graphs

## Build the Project
To compile the project and build all classes, run:
`mvn clean compile`

## Run the Tests
To execute all JUnit 5 test suites (including DSU checks, MST weight agreements, stack safety, and algorithm cross-checks), run:
`mvn test`

## Run the Benchmark
To run the benchmark suite and generate the performance results file (results/results.csv), run:
`mvn exec:java -Dexec.mainClass="benchmark.Benchmark"`
